
# UDCP v5 - Server (Backend)

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Setup environment
cp .env.example .env
# Edit .env if needed

# 3. Run migrations (SQLite)
npm run migrate

# 4. Seed test data
npm run seed

# 5. Start development server
npm run dev

## 📡 Endpoints

- **HTTP API:** `http://localhost:4000/api/*`
- **WebSocket:** `ws://localhost:8080`
- **SSE Events:** `http://localhost:4000/api/events`

## 🧪 Tests
npm test
```
